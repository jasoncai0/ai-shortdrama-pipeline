## 5.5 场景层（SCENE：集和镜之间的戏剧引擎）

集 → 镜跳太快会写出“没引擎的镜头”。中间补一层场景（Scene）：一集拆成几场戏，每场先写场景头部再排镜。

这是把“戏剧逻辑驱动生产”落到实处的一层，也是削减无聊最大的杠杆（对立目标 = 场景的发动机）。

### 每场场景头部（写在该场分镜前）

```text
SCENE #

- 场景目标：这场戏要把局势推到哪（对应一个 State Delta）
- 在场角色目标：每个在场角色：当下目标 + 用什么手段（战术）+ 谁/什么挡着他
- 冲突线引用：本场推进哪条[冲突线]（§3），把它的升级档 +?
- 秘密动作：本场是否触碰某条[秘密排期]（§3）：埋 / 逼近 / 揭
- 情绪落点：本场结束时情绪停在哪（喂上面的情绪曲线）
```

### 场景级 delta 强制（取代“每镜强制”）

每一场必须净产生至少一个 State Delta（情绪 / 认知 / 关系 / 权力其一发生位移），否则这场戏可删或合并。

镜头层保持宽松——单个 shot 可以只是反应、铺垫、或“反转前一拍静默”，只要它服务本场的目标推进即可。这样既保证“场场有戏”，又不扼杀节奏所需的呼吸点。

对立的具体目标是好戏的根：A 想拿到证据、B 想拖住 A，对白和动作就是双方的攻防。没有对立目标的场景 = 没有引擎，直接重写或删。
