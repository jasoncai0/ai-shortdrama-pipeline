## 7. 输出前自检清单

### 7.0 动作意图 / 对手身份 / 群众随机脸自检

- ACTION STATE：每个关键动作是否写清楚 Actor / Action / Target / Motivation / Method / EmotionalState / PowerMeaning / Result？
- OPPONENT / PARTIAL BODY：OTS、手部、背影、遮挡人物是否标明 BelongsTo？
- EXTRAS：群众脸是否随机多样、不得像任何已确认主角？

### 7.1 视觉资产自检

- WORLD_VISUAL_BIBLE 是否实际生成图片并被用户确认？
- CHARACTER @base 是否为白底 / 浅灰底三视图全身真人棚拍参考？
- 三视图图像内是否无任何文字、标签、FRONT/SIDE/BACK、姓名、身份栏？
- @sheet 是否只用于人类审阅，不直接喂 I2V？

### 7.2 v34 镜头生产自检

必须检查（戏剧优先，受 §0.1K / §0.1L 覆盖）：

```text
- 这场戏的情绪 / 信息 / 冲突有没有被演出来（不是被摘要）？
- 有没有为了凑碎镜头，把完整台词或情绪铺垫硬切断？
- 有没有为了偷懒，用无表演支撑的呆板长镜头糊弄？
- 切点是不是踩在戏剧节拍上（反打 / 证据 / 反应 / 爽点），而非机械均匀切？
- Can Be Edited By MICRO_SHOT_UNIT: yes / no（EDL 能否按碎镜头切片）
```

可选事后描述（仅供回看，不作门禁）：MICRO_SHOT_UNIT 数、VIDEO_GENERATION_TASK 数、平均时长、硬切数、反应镜 / 道具镜数；数量只对照软区间（§0.1L、§二/§三），落在区间外触发 review，不单独判失败。

以下**结构性**问题仍直接失败（与数量、时长无关）：

```text
用无表演支撑的呆板长镜头铺满整集
完整核心台词 / 情绪铺垫被硬切碎（见 §0.1K）
EDL 无法按 MICRO_SHOT_UNIT 切片
没有 SHOT_KEYFRAME LIST
没有 VIDEO_GENERATION_TASK PLAN
没有 BATCH_KEYFRAME_SEQUENCE
没有 SELECTS_EDL BY MICRO_SHOT_UNIT
```

### 7.3 Prompt / 音频自检

- Prompt 是否使用 KEYFRAME，而不是首尾帧？
- Batch prompt 是否明确不要合并成 continuous long take？
- 台词是否中文原文、禁止翻译、禁止音乐？
- 关键帧 / I2V 输入是否无字幕、无文字、无 UI？

### 7.4 EDL 自检

- EDL 是否按 Source Video Task + Source Micro Shot Unit 选段？
- 是否标注 recommended_in / recommended_out / selected_duration？
- 是否统计硬切点、平均镜头长度、反应镜、道具镜？
