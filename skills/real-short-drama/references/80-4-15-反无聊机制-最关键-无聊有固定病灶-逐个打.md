## 4.15 反无聊机制（最关键——无聊有固定病灶，逐个打）

无聊不是玄学，它有四个固定病灶，每个对应一条硬动作。

### 病灶① 泛泛 → 具体性强制

任何“概述式”写法都要落到具体细节。

不是“前夫羞辱她”，是写出他说的那句话、当着谁、为了什么。

检验：把句子里的专有信息（人名 / 数字 / 具体物件 / 具体台词）去掉后还成立 → 太泛，重写。

### 病灶② 可预测 → 套路 ≠ 可预测

短剧观众要套路（打脸 / 逆袭），但讨厌可预测的执行。

写完一拍问：“懂行的观众猜得到下一步吗？”

猜得到就给套路一个新鲜的拐弯（换手段 / 换时机 / 换代价），而不是换掉套路本身。

### 病灶③ 概述代替演出 → 禁止“摘要戏”

凡是冲突点 / 爽点 / 反转，必须写成有台词、有动作、有反应镜头的场面，不许用“她反驳了他”“两人大吵一架”一笔带过。

该出刀的地方必须出那把刀。

### 病灶④ 开头留不住 → 前 3 秒划走测试

开篇 3 秒内必须有危险 / 悬念 / 反常信号让人不划走。

### 核心动作：划走点检测（每集输出前必跑）

把这一集当成“凌晨刷手机、拇指随时要划走”的观众来读一遍，标出你第一个想划走的那一秒。

那一拍就是问题——按上面①②③对症重写它（更具体 / 更出乎意料 / 更高赌注 / 真把场面演出来）。

重复，直到你找不到明显的划走点。

### 关键节点出变体

开场钩子、每个大爽点、每个 cliffhanger，先写 2–3 个不同执行，挑最不套路、冲击最大的那个，别用蹦出来的第一个（第一个通常最泛）。
