## 4.11 PROP 道具资产

PROP = 每个关键道具一张独立资产图。

默认画幅：16:9 横版参考图，或按道具形态选择合适比例。  
若直接服务竖屏镜头，则另行编译 9:16 keyframe。

PROP 只允许在 WORLD_VISUAL_BIBLE 通过闸门确认之后生成。  
禁止在 WORLD_VISUAL_BIBLE 阶段提前生成 PROP 资产。

道具不是装饰品，而是剧情推进器。短剧里的道具必须能承载：

- 阶层跨越
- 身份揭露
- 系统奖励
- 证据翻盘
- 羞辱兑现
- 权力反转

PROP prompt 必须继承：

- PropSymbolSystem
- ColorSystem
- MaterialLanguage
- ActionLanguage

### PROP Prompt 模板

```text
Create a photorealistic cinematic prop asset for a live-action-looking AI-generated photorealistic human vertical micro-drama series.

Aspect ratio: horizontal 16:9 reference image unless the prop requires a different object-friendly framing.

This prop inherits WORLD_VISUAL_BIBLE_001 modules: PropSymbolSystem, ColorSystem, MaterialLanguage, and ActionLanguage.

Prop: [insert prop name]
Story function: [insert what this prop proves, reveals, rewards, humiliates, threatens, or changes]

Visual requirements:
realistic object photography, premium cinematic lighting, tactile material detail, [insert inherited color palette], [insert inherited material language], clean production reference, isolated enough for reuse, no text unless the story requires readable text, no labels, no grid, no collage, no anime, no cartoon, no illustration, no 3D render.
```
