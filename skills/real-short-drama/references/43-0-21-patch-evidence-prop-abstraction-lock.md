## 0.21 PATCH：EVIDENCE PROP ABSTRACTION LOCK

### 证据道具抽象化与文字污染防护锁

【补丁目的】

修复以下问题：

1. 短剧常用合同、欠条、病历、胸牌、手机记录、转账单、亲子鉴定、股权书等证据道具，但 AI 图像 / 视频无法稳定生成可读文字。
2. 模型生成乱码文字、漂移 UI、错字合同、伪造病历感，污染成片。
3. 剧情过度依赖观众“看清文件内容”，导致 AI 视频不可落地。
4. 证据镜头被误写成可读文字特写，而不是道具存在感 + 角色反应 + 后期字幕解释。

从本补丁生效起，凡是剧情依赖证据类道具，必须执行 `EVIDENCE PROP ABSTRACTION`。

### 一、证据道具范围

以下全部属于高风险证据道具：

```text
合同
欠条
借据
转账记录
汇款单
股权书
亲子鉴定
病历
诊断书
手术通知
律师函
录音文件
聊天记录
手机来电
医院胸牌
工牌
身份证件
结婚证
离婚协议
收养证明
旧照片背面文字
公司文件
新闻报道
判决书
举报材料
```

### 二、核心原则

AI 图像 / 视频只生成“证据道具的存在感”，不得承担“可读信息传递”。

关键信息必须进入：

```text
Dialogue CN
OS / VO
TTS
subtitle_text
后期图文层
角色反应
第三方确认
```

不得依赖：

```text
AI 直接生成可读文件正文
AI 直接生成可读手机 UI
AI 直接生成可读胸牌姓名
AI 直接生成可读合同条款
AI 直接生成可读病历
AI 直接生成可读欠条金额
```

### 三、正确表达方式

#### 错误

```text
镜头特写欠条，上面清楚写着“沈宏远欠周桂兰二十万元”。
```

#### 正确

```text
泛黄欠条被压在桌面，纸张有折痕和接触阴影；镜头不要求可读文字。林晚用中文台词说出欠条内容，沈宏远看到纸张后手指发抖。
```

#### 错误

```text
手机屏幕显示转账记录和日期。
```

#### 正确

```text
手机屏幕亮起但不显示可读 UI，屏幕反光遮住细节。林晚把手机转向当事人，当事人脸色骤变。转账信息通过对白 / 字幕文本交代。
```

#### 错误

```text
医院胸牌清晰显示“林晚，心外科主任”。
```

#### 正确

```text
医院胸牌作为身份道具落在桌面，画面只表现胸牌形态、挂绳、金属夹和医院感设计，不要求可读文字。身份由台词和旁人反应确认。
```

### 四、证据三件套

每个证据爽点必须包含：

```text
1. Evidence Object:
证据道具出现。

2. Evidence Interpretation:
通过台词 / OS / VO 解释证据内容。

3. Evidence Reaction:
当事人或旁观者出现无法伪装的反应。
```

如果只有证据道具，没有解释，不成立。  
如果只有解释，没有道具，不够爽。  
如果没有当事人反应，爽点不落地。

### 五、SHOT UNIT 字段补充

凡是含证据道具的 SHOT UNIT，必须新增：

```text
Evidence Prop Control:
- Evidence Type:
- Visual Form:
- Is Readable Text Required: no
- Information Delivery Method: dialogue / OS / VO / subtitle_text / reaction / post-production graphic
- Character Who Confirms Evidence:
- Reaction Required:
- Forbidden:
  - readable text generated by AI
  - clear UI text
  - document body close-up
  - fake legal / medical text
  - random letters
  - watermark
```

### 六、Prompt 强制语句

证据类 keyframe / I2V prompt 必须加入：

```text
the document or screen is visible only as a physical evidence prop, no readable text, no legible UI, no clear words, no random letters, no fake document text, key information delivered through Chinese dialogue and post-production subtitles only
```

### 七、输出前自检

- 是否出现合同 / 欠条 / 手机 / 病历 / 胸牌 / 证件？
- 是否错误要求 AI 生成可读文字？
- 关键信息是否进入对白 / OS / VO / 字幕文本？
- 是否有角色反应确认信息？
- 是否避免清晰 UI 和文件正文？
- 是否把证据拍成“物体 + 反应”，而不是“文字阅读”？

### 八、口诀

证据可以出现，文字不能靠 AI 读。  
文件负责存在感，信息交给台词和字幕。  
手机只发光，不读 UI。  
欠条只压桌，不靠模型写字。  
证据必须有反应，否则不爽。
