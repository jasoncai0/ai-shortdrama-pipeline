## 4.16 AI 视频落地约束（v34：碎镜头 + 批量关键帧任务）

短剧靠对白、反应、道具插入、权力角度和爽点兑现推进。v34 不再把“视频生成单元”写成 4-15s 长 SHOT UNIT，而采用：

```text
MICRO_SHOT_UNIT → SHOT_KEYFRAME → VIDEO_GENERATION_TASK → SELECTS_EDL
```

### A. 基础落地约束

- 最终视频默认 9:16 竖屏，1080×1920。
- 最终视频对白使用已确认的作品语言；英文只用于 prompt 编译字段。
- 单张关键帧图、I2V 输入图禁止字幕、台词、标题、标签、UI 字、信息栏或任何文字。
- `MICRO_SHOT_UNIT` 是碎镜头，默认 1-6s；对白镜头最高 8s。
- `VIDEO_GENERATION_TASK` 是一次视频生成提交，默认包含 3-6 个 MICRO_SHOT_UNIT，总时长 6-15s，最多 18s。
- 一致性靠 @base / 已确认关键帧；不得直接喂整张 @sheet 或 WORLD_VISUAL_BIBLE。

### B. MICRO_SHOT_UNIT 生成规则

`MICRO_SHOT_UNIT` = EDL 最小剪辑单位，不是一次视频生成任务。

每个 MICRO_SHOT_UNIT 必须有：

```text
micro_shot_id
duration
hard_cut_role
shot_keyframe_id
visual_function
composition
shot_size
camera_angle
action_moment
dialogue_cn
expected_use
```

### C. VIDEO_GENERATION_TASK 生成规则

`VIDEO_GENERATION_TASK` = 一次提交给 Seedance / I2V 的 batch 任务。

```text
Included Micro Shot Units: 3-6
Total Generated Duration: 6-15s, max 18s
Generation Mode: batched keyframe-guided micro-shot sequence
```

Prompt 必须说明：

```text
This task contains multiple micro shot units. Maintain clear boundaries between micro shots. Do not merge the whole task into one long continuous take.
```

### D. 禁止恢复旧逻辑

禁止：

```text
SHOT UNIT = 一次提交给 Seedance 的 4-15s 连续视频生成需求
MICRO BEAT 可以细，SHOT UNIT 不能碎
60 秒目标 6-10 个 SHOT UNIT
90 秒目标 12 个 SHOT UNIT
single continuous shot 作为 batch 默认
```
