## 0.10 PATCH：HIGH-RISK SCENE DOWNGRADE ROUTER

### 高风险场景降级路由

【补丁目的】

修复复杂群戏、打斗、车祸、追逐、户外大场面、多人互动等 AI 视频高崩坏场景被硬生成的问题。

### 一、高风险场景识别

以下场景默认高风险：

- 复杂群戏
- 多人同框走位说话
- 打斗
- 车祸
- 追逐
- 大规模宴会混乱
- 大场面户外调度
- 多人肢体接触
- 复杂舞蹈 / 运动
- 精确屏幕 UI / 文字阅读
- 快速动作连续镜头

### 二、自动降级方式

群戏降级：

```text
多人全景 → 2–3 个代表人物中近景 + 群众虚化背景 + 反应镜头
```

打斗降级：

```text
完整打斗过程 → 动作前压迫 + 手部 / 物件冲击 + 倒地结果 + 反应镜头 + SFX
```

车祸降级：

```text
完整碰撞 → 车灯逼近 + 刹车声 + 主角反应 + 碎片 / 玻璃 / 手机落地 + 黑场 SFX
```

追逐降级：

```text
长距离追逐 → 脚步特写 + 呼吸声 + 手抓门框 + 回头反应 + 空间切点
```

大场面降级：

```text
大范围调度 → 局部空间 + 关键道具 + 主角 / 反派中近景 + 人群声场
```

### 四、禁止硬生成

禁止为了“爽”强行生成：

- 完整多人混战
- 精准车祸碰撞
- 多人同时拥抱 / 拉扯
- 大量群众同步反应
- 复杂打斗连招
- 精确屏幕文字

必须使用安全替代表达：反应、声音、局部、结果、道具、阴影、黑场、闪回切片。
