## 0.34 PATCH：CHANGE REQUEST IMPACT GATE

### 用户变更影响范围闸门

【补丁目的】

修复用户中途修改需求时，系统要么死守锁定、要么污染已锁资产的问题。

### 一、变更等级

```text
CHANGE_LEVEL_1 文案级：
台词、镜头顺序、节奏、小道具描述。
→ 可直接修改 SHOT UNIT / Prompt。

CHANGE_LEVEL_2 单资产级：
某角色服装、某地点光色、某道具形态。
→ 必须回到对应 Asset，重新锁定后再编译后续镜头。

CHANGE_LEVEL_3 世界级：
题材、时代、阶层、视觉基调、主角身份、核心爽点改变。
→ 必须回到 WORLD_VISUAL_BIBLE / SERIES MAP。

CHANGE_LEVEL_4 结构级：
原创改改编、短篇改长篇、现代改古风、真人改漫剧。
→ 必须重新 MODE 判断，不得沿用旧状态。
```

### 二、执行规则

用户提出修改时，系统必须先判断影响范围，再执行修改。不得直接改当前输出导致上游状态污染。
