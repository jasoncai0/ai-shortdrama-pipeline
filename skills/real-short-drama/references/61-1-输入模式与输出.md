## 1. 输入模式与输出

### 先判定模式（STEP 0）

- **MODE A 原创**：用户给题材 / 一句 logline + 集数 → 从零设计。
- **MODE B 改编**：用户给已有小说 / 网文 / 脚本 → 重切成短剧（很多用户属于这类）。
- **MODE C 续写**：用户回贴了 §3 运行时状态 → 接着往下做。

### 关键变量（缺则按默认并标注，不要写死）

- `episode_length` 单集时长：默认 60–90s（国内小程序常见 1–2min）。
- `monetization`：`iap_unlock`（按集付费，需卡点）/ `ad_unlock` / `free`（靠完播）。决定有无卡点及位置。
- `market`：`cn`（过广电 / 平台审核）/ `overseas`（过 ReelShort / DramaBox 等口径）。决定审核尺度。

### 输出结构（按序）

1. CONCEPT / 改编策略
2. SERIES MAP / 重切集表
3. WORLD VISUAL BIBLE 世界视觉设定板（一张完整 16:9 横版设定定调图，固定信息板 prompt / 或直接生成图）
4. CHARACTER ASSET GENERATION PLAN 角色资产包计划（先列每个角色需要几张 @base、几张 @sheet，禁止盲目批量生图）
5. CHARACTER ASSET PACKAGE 角色资产包（主角 / 重要角色必须完整跑完：@base 生成 → BASE CONFIRMATION GATE 调用 `AskUser` 获得用户确认 → @sheet 生成 → SHEET CONFIRMATION GATE；@base 未确认不得生成 @sheet）
5A. CHARACTER BASE 角色白底三视图全身基准图（每角色 / 每成长阶段先生成 @base，作为最高优先级身份真相源）
5B. CHARACTER SHEET 角色 11 模块表演辅助表（只在对应 @base 已确认后派生；每个角色 1 张横版大图 @sheet，不拆多图，不复刻 base 三视图）
5C. VOICE REGISTRY 角色音色锁定（主角 / 重要角色必须建立 voice_id）
6. LOCATION / PROP / COSTUME 资产（按需逐个出图）
7. EPISODE RELATION MAP / EPISODE SCRIPT DRAFT（单集关系图 + 可拆分初版脚本）
8. EPISODE STORYBOARD / MICRO_SHOT_UNIT（逐集碎镜头 + SHOT_KEYFRAME + VIDEO_GENERATION_TASK + 视频 prompt）
9. NATIVE VIDEO AUDIO REQUEST（§6.5：视频模型原生中文对白 / OS / 环境声 / 必要音效；禁止单片段音乐）
9A. ACTION STATE / OPPONENT IDENTITY / EXTRAS CONTROL（动作意图、对手局部身份、群众随机脸控制）
9B. NATIVE AUDIO FAILURE RECOVERY（原生视频语音失败时修台词 / 镜头 / prompt 并重生成；音乐只允许最终统一添加）
10. RUNTIME STATE（§3，结尾更新）

不必一次跑完整剧。默认顺序：

概念 / 主线（1–2） → 先锁 STORY_FRAMEWORK / SERIES_ENGINE / EP01_DRAMA_BEAT / CHARACTER_FUNCTION_MAP → 再锁 WORLD VISUAL BIBLE 世界视觉设定板（第一张视觉资产） → 先做 CHARACTER ASSET GENERATION PLAN → 再逐个跑 CHARACTER ASSET PACKAGE：生成 @base 白底三视图全身基准图 → BASE CONFIRMATION GATE 调用 `AskUser` 等待用户确认 → 确认后生成单角色 @sheet → SHEET CONFIRMATION GATE → 再做 Voice Registry / 地点 / 道具 / 服装 → 先写 EPISODE RELATION MAP + EPISODE SCRIPT DRAFT → 再按需逐集展开 SHOT UNIT / KEYFRAME / I2V / 原生音频失败修复。

WORLD VISUAL BIBLE 是全片最高世界视觉资产，不是单张背景图，不是一组场景图，不是 gallery，不是 carousel。它必须首先作为一张完整 16:9 横版图片生成，用来完成整部剧的视觉定调。

角色生产必须遵循 BASE FIRST + BASE CONFIRMATION + SHEET SINGLE IMAGE：没有白底三视图全身 @base，不得生成 @sheet；@base 未通过 BASE CONFIRMATION GATE、未获得用户确认 / `user_confirmed=yes`，不得生成 @sheet；@sheet 是每个角色 1 张横版完整大图，内部封装表演 / 情绪 / 头部角度 / 姿态 / 近景 / 服装 / 手部细节，不得拆成多张补充图，不得复刻 @base 三视图；没有 confirmed @base，就不得进入人物视频关键帧。

角色、地点、道具、关键帧都必须继承 WORLD VISUAL BIBLE 拆出的视觉模块，而不是继承一张单独的世界背景图。

WORLD VISUAL BIBLE 未锁定，不得进入角色 / 地点 / 道具资产生产。  
CHARACTER @base 未锁定，不得进入角色 @sheet、人物关键帧、I2V。

### 输出语言

用户可见沟通语言按全局对话语言规则。剧情 / 对白 / 分镜说明使用已确认的作品语言；图像 / 视频画面 prompt 用英文；发给视频模型的对白 / OS 必须保留已确认的作品语言原文。

全片最终视频对白不得默认中文。除非用户或目标市场明确指定中文，否则同期声 / VO / OS / 字幕文本使用已确认的作品语言；作品语言不明确时先通过 `AskUser` 确认。

单张分镜图、SHOT KEYFRAME、I2V 输入图禁止出现字幕、台词、标题、标签、UI 字或任何文字。对白必须写入 shot object 与 Native Video Audio Execution，并在视频请求中要求模型逐字说出已确认作品语言的原文；不得烧进图像。无 TTS 兜底；原生视频音频失败时只能修台词、镜头并重生成。
