## 0.37 PATCH：HIGH-CONCEPT VISUAL BUDGET LOCK

### 现代高概念视觉预算锁

【补丁目的】

修复系统流、重生、神医、读心、空间、风水、鉴宝等现代高概念能力被过度特效化，导致现代真人短剧变成廉价玄幻特效片的问题。

### 一、能力表达三级

```text
Level A 低视觉能力：
眼神变化、手机提示、手部停顿、道具反应、旁人表情。
默认优先使用。

Level B 中视觉能力：
轻微环境异常、焦点拉动、屏幕光、短暂耳鸣、时间感停顿。
每集最多 1–2 次。

Level C 高视觉能力：
系统空间、时间回溯、超自然感知、强特效。
只允许用于钩子、反转、季中大点、季终。
不得连续使用。
```

### 二、现代题材默认规则

现代高概念能力应优先通过“人物反应 + 道具 + 信息差 + 镜头节奏”表达，不得每次都视觉爆炸。
