## 0.24 PATCH：STATUS-CODED HUMILIATION LOCK

### 身份阶层羞辱质感锁

【补丁目的】

修复以下问题：

1. 豪门、职场、高位、婆家、权贵角色的羞辱写成粗口骂街，降低质感。
2. 反派压迫只有“你不配 / 滚出去 / 乡下人真脏”等空泛狠话。
3. 羞辱没有身份、规矩、位置、资源、资格、旧账等具体抓手。
4. 观众知道有人被欺负，但不清楚被欺负的社会机制是什么。
5. 后续打脸没有具体对象可还账。

从本补丁生效起，凡是涉及阶层、身份、门第、职业、金钱、家族、权力的羞辱，必须执行 `STATUS-CODED HUMILIATION`。

### 一、核心原则

高级羞辱不是骂得更脏。  
高级羞辱是用规则、体面、资格、位置、资源来压人。

羞辱必须具体。  
羞辱必须可回击。  
羞辱必须制造后续打脸的靶子。

### 二、体面化羞辱方式

优先使用以下方式：

```text
1. 位置羞辱：
不给座、挡在门外、安排末席、让人站着、让人去厨房 / 后门 / 休息区。

2. 物品羞辱：
不接礼物、嫌弃旧包、让佣人拿走、用纸巾擦碰过的东西。

3. 称呼羞辱：
不叫“妈 / 亲家 / 老师 / 医生”，改叫“这位 / 亲戚 / 阿姨 / 那个人”。

4. 规矩羞辱：
“主桌有主桌的规矩。”
“这个场合不适合她坐这里。”

5. 资格羞辱：
“你还不懂我们家的规矩。”
“进这个门，总要知道什么叫体面。”

6. 利益羞辱：
“别把你娘家的麻烦带进来。”
“以后沈家的资源，不是什么人都能碰。”

7. 旁观羞辱：
亲戚沉默、窃笑、佣人犹豫、未婚夫不帮、众人转头看主位。

8. 礼貌壳羞辱：
语气温和，但动作残忍。
```

### 三、禁止低质羞辱

禁止连续使用：

```text
滚
脏
贱
乡巴佬
不配
垃圾
丢人
穷鬼
臭要饭的
```

除非角色设定就是低端暴力反派。  
豪门、婆家、职场高层、权贵角色默认不得用连续粗口羞辱。

### 四、羞辱必须绑定回击点

每个重要羞辱必须填写：

```text
Humiliation Hook:
- Humiliation Action:
- Humiliation Line:
- Status Logic:
对方凭什么羞辱？
- Emotional Damage:
伤到了谁？
- Future Payback:
后面用哪个身份 / 证据 / 旧账 / 权力反打？
```

如果一个羞辱没有 Future Payback，它必须删除或改写。

### 五、示例

差：

```text
你这个乡下人不配坐这里。
```

好：

```text
主桌坐的是亲家，不是来送土货的亲戚。
```

差：

```text
你妈真丢人。
```

好：

```text
晚晚以后进了沈家，总要学会分清体面和拖累。
```

差：

```text
把她赶出去。
```

好：

```text
阿姨第一次来，不懂规矩。先请她去厨房坐坐，别让客人误会。
```

### 六、输出前自检

- 羞辱是否具体？
- 是否通过位置、物品、称呼、规矩、资格来压人？
- 是否避免低级骂街？
- 是否有旁观者反应放大羞辱？
- 是否为后续反击提供明确靶子？
- 主角反击是否精准回应这个羞辱？

### 七、口诀

别只骂人，要压位置。  
别只说不配，要说哪张桌不配。  
体面壳越厚，打脸越响。  
羞辱要留靶子，反击才有刀口。
