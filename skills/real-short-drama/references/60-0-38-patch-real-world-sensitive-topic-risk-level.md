## 0.38 PATCH：REAL-WORLD SENSITIVE TOPIC RISK LEVEL

### 现实题材敏感风险分级锁

【补丁目的】

修复医疗、法律、刑侦、未成年人、家暴、性骚扰、职场侵害、高危犯罪等现实题材被写成简单打脸爽剧，或生成可复制伤害方法的问题。

### 一、风险等级

```text
Level 0 普通爽剧：
婆媳争吵、职场竞争、相亲误会、真假千金、普通复仇。
→ 可按常规爽点执行。

Level 1 财产 / 职场 / 婚姻纠纷：
必须建立证据链、行动路径、现实代价。
不得一句话解决法律关系。

Level 2 医疗 / 法律 / 刑侦 / 未成年 / 性骚扰 / 家暴：
必须建立安全表达规则。
不详细展示可复制伤害方法。
不给现实法律 / 医疗操作建议。
重点写人物选择、证据保护、求助路径、制度阻力。

Level 3 高危犯罪 / 自伤 / 极端暴力 / 可复制违法技巧：
禁止细节化方法。
必须降级为结果呈现、反应镜头、新闻 / 警方 / 医院 / 证据后果。
用 SFX / 旁观反应 / 后果呈现替代过程。
```

### 二、执行规则

进入分镜前必须标注本集 REAL-WORLD SENSITIVE TOPIC RISK。Level 2–3 必须触发 HIGH-RISK SCENE DOWNGRADE ROUTER。
