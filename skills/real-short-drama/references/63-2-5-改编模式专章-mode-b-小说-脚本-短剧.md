## 2.5 改编模式专章（MODE B：小说 / 脚本 → 短剧）

小说和短剧是两种节奏：小说可以慢热、内心戏多、支线广；短剧必须每集一钩子、每集一悬念断点。改编的核心不是“翻译”，是为竖屏短剧重新切割与提密。

### STEP B1 解析源材料

源可能很长，先抽主干再细做：

- 抽出戏剧主干（核心冲突线）、主要人物、世界设定。
- 标出源里所有天然的爽点 / 虐点 / 反转 / 揭露——这些将成为各集的集高潮。
- 识别连接组织（铺垫、内心独白、支线）——短剧里多半要压缩或砍掉。

### STEP B2 改编策略（明确取舍，写出来）

- 保留：作者的核心剧情、人物三观、关键爽点——不擅自改故事。改动必标注。
- 压缩：长内心戏、慢铺垫 → 用一两个动作镜头或一句台词替代。
- 砍：不服务主干的支线、人物。
- 前置：若原著开篇没钩子，把后面的强冲突 / 揭露提前做开场（短剧前 3 秒定生死）。
- 缺口：源没交代的，小缺口保守补全并标注，大缺口列出来问用户，别瞎编翻车。

### STEP B3 重切集（re-episoding）——改编最值钱的一步

- 密度律：源里没有戏剧转折的段落不单独成集，合并或砍掉。一集 = 一个完整的“压 → 翻 / 揭”动作。
- 断点术：经常在一个爆点正要兑现的前一秒切断作为 cliffhanger（不是在事件结束后切）。
- 钩子化：每集开头都要有钩子，即使源材料该处是平铺直叙。
- 产出重切集表：`E01: 源章节X的Y事件 → 集高潮Z → cliffhanger类型` 逐集列。

之后接 §4 资产、§5 分镜，与原创同管线。改编模式下 Layer 1 大部分来自源材料，本系统的活是“为媒介重构 + 生产化”，不是另写一个故事。
