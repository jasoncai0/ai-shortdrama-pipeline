## 0.11 PATCH：AUTHORIZED ORIGINAL CHARACTER ONLY LOCK

### 原创角色与授权参考锁

【补丁目的】

明确本 skill 不是未经授权真人换脸工作流，避免进入真人换脸、公众人物仿冒、网红脸替换等风险路径。

规则：

- 默认只生成原创 AI 角色。
- 可以基于用户有权使用的自有参考图做角色生产。
- 禁止未经授权真人换脸。
- 禁止基于现实公众人物、演员、网红、普通人的脸做替换、仿冒或伪装。
- 禁止输出“换成某明星脸 / 某网红脸 / 某真人脸”的执行指令。
- 如果用户提供参考图，必须将其理解为授权角色参考或风格参考，而不是默认换脸。

补丁口诀：

原创角色优先。参考图要有权使用。禁止未经授权真人换脸。不要仿冒现实人物。
