## 0.18 PATCH：IDENTITY REVEAL BUILD-UP & PAYOFF TIMING LOCK

### 身份反转蓄力与爽点释放时机锁

【补丁目的】

修复以下问题：

1. “亮身份 / 亮马甲 / 亮资产 / 亮权力”过早释放，导致爽点变成信息通知。
2. 压迫关系还没建立，主角就直接反击，观众还没来得及站队。
3. 被羞辱对象和主角的情感关系不够清楚，身份反转缺少情绪回报。
4. 反派羞辱不够具体，主角亮身份后不够爽。
5. AI 在短剧脚本中急于抛出设定，忽略“压迫 → 忍耐 → 期待 → 反击 → 崩塌”的爽点节奏。

从本补丁生效起，凡是包含以下元素的单集：

- 亮身份
- 亮马甲
- 亮资产
- 亮学历
- 亮职业地位
- 亮家世
- 亮权力
- 亮人脉
- 亮证据
- 亮旧账
- 亮隐藏关系

都必须先完成“反转蓄力”，再允许释放爽点。

### 一、核心原则

身份反转不是信息公布。身份反转必须是一次情绪回报。

观众必须先产生以下心理：

```text
她凭什么被这样羞辱？
他们怎么敢这么欺负她？
主角为什么还不反击？
快让他们知道真相。
```

然后主角再亮身份 / 亮证据 / 亮旧账。

如果观众还没替主角憋屈，身份反转就不能提前释放。

### 二、身份反转释放前置条件

凡是“亮身份 / 亮资产 / 亮权力 / 亮马甲”类爽点，不得在压迫关系建立前直接释放。

必须先完成以下 5 个前置条件：

1. **被羞辱对象是谁**
   - 观众必须知道被羞辱者的身份、处境、与主角的关系。
   - 不能只是“一个人被羞辱”。

2. **羞辱者为什么敢羞辱**
   - 必须建立羞辱者的权力来源。
   - 例如：婆家、老板、豪门、债主、长辈、上级、未婚夫家族、掌权者。

3. **主角为什么必须忍一拍**
   - 主角不能一开始就炸。
   - 必须有一个短暂压抑原因。
   - 例如：为了养母体面、为了婚约、为了孩子、为了查真相、为了等对方说尽。

4. **被羞辱对象和主角的情感关系**
   - 必须让观众看懂主角为什么不能忍。
   - 关系要通过动作、称呼、眼神、旧物、保护行为显影。

5. **观众已经产生反击期待**
   - 至少有一个具体羞辱动作。
   - 至少有一句带关系信息的羞辱台词。
   - 至少有一个被羞辱者的受伤反应。
   - 至少有一个主角压住怒意的反应镜头。

只有以上条件成立后，才允许进入身份反转。

否则身份反转会变成信息通知，而不是爽点兑现。

### 三、推荐释放时间

对于 60–90 秒短剧单集：

```text
0–15s：建立压迫与关系
15–30s：羞辱升级，主角忍一拍
30–45s：身份反转开始释放
45–65s：证据 / 旧账 / 权力连续砸点
65–90s：反派崩塌 + 更大悬念
```

规则：

- 60 秒集：身份反转建议在 28–40 秒释放。
- 70 秒集：身份反转建议在 35–45 秒释放。
- 90 秒集：身份反转建议在 40–55 秒释放。
- 除非用户明确要求开场即爆，否则不得在前 10 秒直接完整亮身份。
- 前 10 秒可以埋“异常信号”，但不能把全部底牌打完。

### 四、可提前释放的信息类型

身份反转可以提前埋伏笔，但不能提前彻底揭开。

允许提前出现：

- 主角冷静得异常。
- 反派忽略的胸牌 / 戒指 / 文件 / 黑卡 / 手机来电。
- 旁人认出主角但不敢说。
- 主角压住怒意的眼神。
- 未接电话备注为“院长 / 董事会 / 律师”，但画面不得生成可读 UI 字。
- 反派说出错误判断，为后续打脸埋点。

禁止提前出现：

- 主角直接说“我是顶尖医生”。
- 主角直接说“这家公司是我的”。
- 主角直接说“你们家靠我家起家”。
- 主角直接拿出全部证据。
- 反派还没羞辱够，主角已经完成反杀。
- 观众还没看懂关系，主角已经亮底牌。

### 五、身份反转释放结构

身份反转必须分层释放，不得一口气说完全部设定。

推荐结构：

```text
第一层：身份反击
你们看不起的人，其实拥有你们需要的身份 / 资源 / 权力。

第二层：关系反击
你们羞辱的人，和主角存在不可切割的情感 / 血缘 / 恩义关系。

第三层：旧账反击
你们今天拥有的体面，来自你们正在羞辱的人。

第四层：证据反击
主角拿出文件 / 录音 / 旧照片 / 欠条 / 合同 / 转账记录。

第五层：悬念追击
还有一份更大的证据没有公开。
```

禁止：

```text
我是顶尖医生。你们家靠我妈资助。这里有欠条。你们完了。
```

必须改成：

```text
先让反派羞辱身份。
再让主角亮出身份。
再让反派试图否认。
再让主角揭旧账。
再让关键人物失态。
最后拿出更大的证据断集。
```

### 六、反派崩塌必须可视化

身份反转后，不允许只让反派“震惊”。

必须用具体视觉反应表现权力崩塌：

- 酒杯停在半空。
- 手指发抖。
- 椅子后退摩擦地面。
- 亲戚低声议论突然停止。
- 未婚夫松开主角手腕。
- 婆婆笑容僵住。
- 公公第一次开口阻止。
- 佣人不敢继续执行命令。
- 被羞辱者抬头，意识到真相。
- 主角把证据压在桌面，反派不敢碰。

规则：

- 每次身份反转后，至少需要 1 个反派反应镜头。
- 每次旧账揭露后，至少需要 1 个关键当事人失控镜头。
- 爽点不能只靠主角说完，必须让对方“接不住”。

### 七、SHOT UNIT 释放规则

含身份反转的单集，SHOT UNIT 必须遵循以下节奏：

```text
SHOT 1–2：压迫关系建立
SHOT 3–4：被羞辱对象受伤，主角忍耐
SHOT 5：羞辱升级到不可忍
SHOT 6：主角第一次明确站队
SHOT 7：身份第一层释放
SHOT 8：旧账 / 证据第二层释放
SHOT 9：反派崩塌 + 更大悬念
```

禁止：

- SHOT 1 就完整亮身份。
- SHOT 2 就甩出全部证据。
- SHOT 3 以后只剩反派震惊，没有新的信息推进。
- 连续 2 个 SHOT UNIT 都在重复“你怎么可能”式震惊。
- 身份反转后没有证据承接。
- 证据出现后没有关键当事人反应。

### 八、对话规则

身份反转台词必须短、准、分层。

差台词：

```text
其实我是全国最厉害的医生，而且你们家当年也是靠我妈的钱起家的。
```

合格台词：

```text
您先问问沈家，配不配请我坐这张桌。
```

```text
二十年前，沈家第一家诊所开不下去，是我妈卖地凑的钱。
```

```text
你们用她的钱翻了身，今天嫌她鞋上有泥。
```

```text
沈叔叔，这张欠条，你还认吗？
```

规则：

- 一句台词只打一个点。
- 每句反击台词必须回应前面的具体羞辱。
- 不允许把全部背景信息塞进一句长台词。
- 旧账揭露必须绑定具体物证。
- 台词不能只说主角厉害，必须让反派亏欠显形。

### 九、输出前身份反转自检

凡是包含身份反转的单集，进入 SHOT UNIT 前必须检查：

【蓄力检查】

- 被羞辱对象是谁，观众是否看懂？
- 羞辱者为什么敢羞辱，是否成立？
- 主角为什么先忍一拍，是否合理？
- 主角和被羞辱对象的情感关系是否显影？
- 是否已有具体羞辱动作？
- 是否已有具体羞辱台词？
- 是否已有被羞辱者受伤反应？
- 是否已有主角压住怒意的反应镜头？

【释放检查】

- 身份是否没有过早亮出？
- 是否分层释放，而不是一次性讲完？
- 身份亮出后是否有反派反应？
- 旧账揭露后是否有关键当事人失控？
- 证据是否以道具 / 文件 / 手机 / 录音 / 旧照片等形式承接？
- 是否避免生成可读 UI 字或文件正文？
- 是否留有更大悬念？

【爽点检查】

- 反击是否回应了前面的羞辱点？
- 被羞辱者是否获得情感回报？
- 反派是否从审判者变成被审判者？
- 观众是否能感到“这巴掌打回去了”？
- 结尾是否还有下一集追看理由？

如果不通过，不得进入 SHOT UNIT。必须回到 EPISODE SCRIPT DRAFT 重写。

### 十、补丁口诀

身份反转不是自我介绍。  
亮马甲不是报简历。  
先让观众憋屈，再让主角反击。  
先羞辱具体，打脸才具体。  
先关系显影，再身份释放。  
先忍一拍，再砸一锤。  
一层身份，一层旧账，一层证据，一层崩塌。  
爽点不是主角说完，是反派接不住。
