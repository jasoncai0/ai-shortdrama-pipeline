## 0.4 PATCH：EPISODE RELATION CLARITY & SCRIPT DENSITY LOCK

### 单集人物关系清晰度与可拆分脚本密度锁

【补丁目的】

修复以下问题：

1. 第一集有钩子，但人物关系不清楚，观众不知道谁和谁是什么关系。
2. 角色一个个出现，但彼此之间缺少因果连接，画面像随机片段。
3. AI 在脚本不够清晰时直接拆分镜，导致镜头跳跃、关系断裂、冲突不合理。
4. 分镜只表现“有人说话”，没有表现“谁压迫谁、谁亏欠谁、谁背叛谁、谁掌控谁”。
5. 观众看不懂主角为什么受辱、为什么反击、为什么此刻必须行动。

从本补丁生效起，任何单集进入分镜前，必须先完成：

```text
EPISODE RELATION MAP
→ EPISODE SCRIPT DRAFT
→ SCENE BREAKDOWN
→ SHOT UNIT
```

禁止从 SERIES MAP 直接跳到 SHOT UNIT / 分镜。

### 一、核心原则

短剧第一集不是只负责制造钩子。第一集必须同时完成：

1. 让观众知道主角是谁。
2. 让观众知道主角和关键人物是什么关系。
3. 让观众知道谁压迫主角。
4. 让观众知道主角失去了什么。
5. 让观众知道主角为什么不能不反应。
6. 让观众知道反击对象是谁。
7. 让观众知道本集结尾的悬念为什么重要。

钩子必须建立在清晰关系之上。  
如果关系不清，钩子只会变成噪音。

### 二、EPISODE RELATION MAP 单集关系图

每一集进入脚本前，必须先输出 EPISODE RELATION MAP。

```text
EPISODE RELATION MAP

本集核心关系问题：
观众这一集必须看懂哪组关系？

核心人物：
- CHAR_xxx：
  - 本集身份：
  - 与主角关系：
  - 当前对主角的态度：
  - 欠主角什么 / 从主角身上拿走什么：
  - 想让主角失去什么：
  - 本集压迫手段：
  - 观众首次理解该关系的镜头 / 台词：

关系显影方式：
- 用哪个动作让观众看懂关系？
- 用哪句台词让观众听懂关系？
- 用哪个站位 / 道具 / 眼神让观众感受到权力差？
```

规则：

- 每个重要角色第一次出场时，必须说明他和主角的关系。
- 每个压迫者必须有明确压迫理由。
- 每个羞辱动作必须绑定关系历史。
- 每个反击对象必须提前让观众知道他“欠了什么账”。
- 不得让角色无关系地突然出现、突然攻击、突然反应。

### 三、EPISODE SCRIPT DRAFT 可拆分初版脚本

在分镜前，必须先写 EPISODE SCRIPT DRAFT。

它不是最终文学剧本，也不是分镜。  
它是给 AI 拆分镜用的“逻辑连续脚本”。

EPISODE SCRIPT DRAFT 必须满足：

- 按真实观看顺序写。
- 每一场都有明确起因、冲突、反应、结果。
- 人物关系必须在动作和台词中显影。
- 不允许只有概述。
- 不允许只写“她被羞辱”“他反击了”。
- 必须写出具体动作、具体台词、具体反应。
- 必须让后续分镜可以自然拆出 SHOT UNIT。

```text
EPISODE SCRIPT DRAFT

E{编号} 标题：

本集一句话：
本集核心关系：
本集核心冲突：
本集观众必须看懂的信息：
本集结尾悬念：

SCENE 1：
地点：
在场角色：
场景开始时的关系状态：
场景目标：
Because 因为：
But 但是：
Therefore 所以：
剧情展开：
- 具体动作：
- 具体台词：
- 具体反应：
- 关系信息如何被观众看懂：
场景结束时的状态变化：
```

### 四、关系显影强制规则

每个重要人物第一次出现，必须通过以下至少两种方式显影关系：

1. **称呼关系**：前夫、未婚妻、继母、老板、债主、姐姐、养女、少爷、司机、秘书。
2. **权力动作**：不给座、打断说话、递文件不看人、让人站着、故意无视、当众命令。
3. **关系历史台词**：如“三年前是你求我订婚。”“你爸欠的债，今天该你还。”
4. **道具关系**：婚戒、离婚协议、亲子鉴定、股权书、债务单、旧照片、录音、房卡。
5. **站位关系**：主角被挡在门外，反派坐在主位，旁观者围着权力方。
6. **旁观者反应**：众人沉默、窃笑、躲开主角、转向反派、服务生不敢递水。

禁止：

- 人物出现但观众不知道他是谁。
- 人物攻击主角但没有关系原因。
- 主角反击但观众不知道她为什么有资格反击。
- 反派羞辱但没有具体羞辱点。
- 只靠角色名解释关系。
- 只在人物表里写关系，不在剧情中演出来。

### 五、第一集关系信息密度要求

E01 必须在前 20 秒内交代清楚至少一组核心关系。

E01 前 20 秒必须包含：

- 主角当前处境
- 一个明确压迫者
- 一个明确关系标签
- 一个具体羞辱动作
- 一个关系历史信息
- 一个观众能理解的“主角为什么不能忍”的理由

如果前 20 秒只有视觉钩子，没有关系信息，则判定失败。

### 六、台词关系密度规则

第一集重点台词必须同时承担“攻击 + 关系说明”。

差台词：

```text
你不配站在这里。
```

合格台词：

```text
三年前是沈家求你订婚，今天是沈家亲手把你赶出去。
```

规则：

- 重要台词必须尽量包含关系、历史、利益、威胁中的至少两项。
- 羞辱台词必须具体到身份、金钱、婚姻、血缘、权力、秘密或债务。
- 反击台词必须回应前面某个具体羞辱点。
- 不允许空泛狠话连续出现。

### 七、场景因果链强制

每一场必须写清楚：

```text
Because 因为：
But 但是：
Therefore 所以：
```

如果一场戏无法写出 Because / But / Therefore，则该场戏关系因果不成立，必须重写。

### 八、分镜拆分前检查

只有 EPISODE SCRIPT DRAFT 通过以下检查后，才允许进入 SCENE BREAKDOWN / SHOT UNIT：

- 主角和核心对手的关系是否清楚？
- 观众是否知道谁压迫谁？
- 观众是否知道压迫发生的原因？
- 观众是否知道主角损失了什么？
- 观众是否知道主角为什么必须反应？
- 每个重要角色第一次出场是否有关系标签？
- 重要台词是否携带关系信息？
- 每场是否有 Because / But / Therefore？
- 是否有具体动作，而不是概述？
- 是否有具体反应，而不是只推进事件？
- 是否能自然拆成 SHOT UNIT？

如果不通过，不得进入分镜。

### 九、SHOT UNIT 关系字段补充

每个 SHOT UNIT 必须新增以下字段：

```text
Relationship Information:
本片段让观众看懂哪一层人物关系？

Relationship Visual Cue:
通过什么画面让观众看懂？站位 / 眼神 / 道具 / 称呼 / 动作 / 旁观者反应。

Relationship Dialogue Cue:
哪句中文台词交代或强化了关系？

Causal Link:
本片段和上一个片段的因果连接是什么？
```

规则：

- 如果一个 SHOT UNIT 没有关系信息，也没有推进关系变化，它必须服务明确的情绪停顿 / 道具揭露 / 爽点砸点。
- 不允许连续 2 个 SHOT UNIT 都无法说明人物关系或因果推进。
- 重要反打镜头必须说明“这句话改变了对方什么状态”。

### 十、输出前关系清晰度自检

每集输出前必须检查：

【关系可读性】

- E01 前 20 秒是否交代至少一组核心人物关系？
- 主角和核心对手的关系是否能被观众听懂或看懂？
- 每个重要角色第一次出场是否有关系标签？
- 是否有具体称呼 / 道具 / 站位 / 旁观者反应来显影关系？
- 是否避免角色无关系地突然出现？

【因果连续性】

- 每场是否有 Because / But / Therefore？
- 每个 SHOT UNIT 和上一个 SHOT UNIT 是否有因果连接？
- 是否避免“一个人说话，然后下一个片段突然来了”的跳跃感？
- 是否每个冲突动作都有动机？

【脚本密度】

- 是否在分镜前完成 EPISODE SCRIPT DRAFT？
- 初版脚本是否足够细，可以自然拆分镜？
- 是否避免只有大纲、没有动作和反应？
- 重要台词是否同时包含攻击和关系信息？

如果不通过，必须回到 EPISODE RELATION MAP 或 EPISODE SCRIPT DRAFT 重写，不得直接修分镜。

### 十一、补丁口诀

先让观众看懂关系，再让观众爽。  
钩子不是噪音，钩子必须挂在关系上。  
人物第一次出现，必须带关系。  
羞辱必须有历史，反击必须还账。  
分镜前先写可拆分脚本。  
脚本不清，分镜必跳。  
每场 Because / But / Therefore。  
每个 SHOT UNIT 都要知道它接的是谁、压的是谁、变的是什么关系。
