## 0.6 画幅规则（必须遵守）

不同生产资产使用不同默认画幅，严禁混用：

- **WORLD_VISUAL_BIBLE / Moodboard / 世界视觉设定板**：默认 16:9 横版，用于承载九宫格信息板、视觉定调、世界规则、色彩光影、场景方向、道具符号、情绪曲线。
- **CHARACTER @base**：默认 16:9 或 4:3 横版白底 / 浅灰底三视图全身图，一张图内包含同一角色正面 / 侧面 / 背面完整全身视图，用于锁定角色脸、骨相、身材、服装比例，服务 img2img / I2V / 关键帧生产。
- **CHARACTER @sheet**：默认 16:9 或 4:3 横版设计表，固定 11 模块（Module 03 为约 20-25% 的 @base 紧凑三视图继承区，锁同一身份、不得撑满全图），用于给人查看表情 / 微表情 / 头部 / 姿态 / 近景 / 服装 / 手部等表演细节。
- **LOCATION / PROP / COSTUME**：按资产需要决定，默认可用 16:9 横版参考图；若直接服务竖屏镜头，则另行编译 9:16 keyframe。
- **EPISODE STORYBOARD / SHOT KEYFRAME / I2V VIDEO**：默认 9:16 竖屏，1080×1920，服务最终短剧成片。

核心规则：

设定板为了信息密度使用 16:9；成片镜头为了平台播放使用 9:16。  
上游视觉宪法横版承载信息，下游镜头编译成竖屏成片。
