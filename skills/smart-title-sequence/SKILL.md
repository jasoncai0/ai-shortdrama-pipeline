# 智能片头生成

把片名作为镜头中的视觉主体，而不是后加的一层字幕。基于已有视频片段或关键帧，完成镜头分析、标题导演、融合式关键帧、动态片头与针对性修改。

## 收集 Brief

提取或收集：视频片段/关键帧、片名原文、题材与故事调性、目标时长、画幅、参考、禁用元素和平台。片名原文必须锁定，不得改写。

未给出时，默认交付 4 秒、原始画幅、三个候选方向：稳妥版、叙事融合版、侵入版。只有片名或交付画幅缺失时才追问；其他信息先做清楚标注的创作假设。

用户明确要求找公开参考时，使用 `WebSearch`；用户要使用自己的 Pinterest 素材时，使用 `ConnectorPicker`。没有这两类意图时，不主动检索。

## 先写标题导演单

在生成前先用以下字段作出简短决定，并在输出中展示：

```text
标题角色：主视觉 / 叙事融合 / 隐性彩蛋
构图预设：保守 / 叙事 / 侵入
占比：最小画幅宽度与高度
越界：允许裁出哪些边界
透视：平面 / 浅透视 / 强透视
完整可读：至少停留多少秒
叙事行为：被遮挡 / 受压 / 被吞没 / 出逃 / 侵入 / 重组
```

规则：主视觉标题高度不得低于画幅 18%，完整可读至少 1.5 秒。长片名优先分行、断行、错位或裁边，不能为完整容纳而压扁字体。创意透视、环境融字与遮挡型标题优先用浅透视；强透视只在其本身就是叙事目的时使用。

### 构图预设

- **保守**：宽度 70–90%，完整位于安全区；用于封面、缩略图和信息型片头。
- **叙事**：宽度 90–115%，允许被主体局部遮挡；用于情绪和剧情镜头。
- **侵入**：宽度 120–160%，允许裁出 1–2 条边界；用于惊悚、犯罪、荒诞和强作者表达。

越界必须看起来有意为之：保留足够笔画以便识别，用粗壮、完整的字形制造标题正在进入或侵占画面的感觉。

## 分析镜头与选择策略

识别人物、前中后景、建筑/道具、留白、现有字幕、光源、材质、镜头方向和可遮挡标题的主体。不得破坏人物脸部、关键动作或叙事道具。

提出三个差异明确的方案，并说明标题位置、互动对象、材质、入退场、时长和剧情理由。可选择：

- 留白叠印：用于天空、墙面、暗部或虚化区域。
- 环境融字：让标题存在于光、雾、水面、田野、墙体等场景材质中。
- 自然遮挡：让人物、植物、建筑、门窗或道具处于标题前方。
- 材质化标题：使用水墨、石刻、玻璃、金属、霓虹、织物或火焰，但材质必须回应故事世界。
- 粒子显现：以尘粒、墨迹、萤火、纸屑、雨滴或能量碎片聚散片名。
- 标题卡/转场：当镜头信息过满或需要情绪断点时使用。

## 生成与动态化

对已有镜头的局部标题融合，使用 `EditMedia`；需要改变主体状态、生成新关键帧或制作标题动画时，使用 `GenerateMedia`。把片名原文与标题导演单中的占比、越界、透视和可读性放在提示词最高优先级。

动效只服务标题的叙事行为，可使用缓慢浮现、光扫、风动、雾气消散、粒子聚散、微视差和与镜头同步的运动。避免频繁闪烁、无理由的形变和抢戏特效。已有片段需要拼接、混音、字幕或最终封装时，再使用 `FinishingTool`。

## 质检与定向返工

逐项检查：

1. 片名、标点和副标题原文准确。
2. 主视觉标题先于环境细节被看见。
3. 光源、颜色、透视、景深、遮挡和接触关系一致。
4. 无标题跳变、字形形变、闪烁、粒子噪点、主体身份漂移或连续性破坏。

把反馈翻译成单独的控制变量，不要无目标整体重做：

| 用户反馈 | 优先修改 | 不要误改 |
| --- | --- | --- |
| 字太小 | 提高字高、分行、降低透视压缩、切换侵入版 | 只横向拉宽 |
| 没有片名感 | 提升标题角色、对比、字重和停留时长 | 只加粒子或发光 |
| 太中规中矩 | 允许 1–2 边越界、错位或强裁切 | 增加无关特效 |
| 融得不自然 | 固定尺度，调整材质、光线、遮挡和透视 | 缩小标题 |
| 抢戏 | 保留标题尺度，降低动效速度、反光和粒子密度 | 直接缩小标题 |

## 交付

交付主推荐成片、至少两个候选方向、带片名关键帧，以及可用时的无字底片。简短说明标题导演单、动效、时长、画幅和仍需确认的风险。
