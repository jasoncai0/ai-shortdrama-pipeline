# Bilibili Cover Reference

Use for Bilibili/B站/BV/UP主 covers. Default 16:9 (1920x1080 or 1280x720), with title and faces inside a generous central safe zone. This is Chinese mobile-feed, high-CTR packaging: dense enough to create an information gap, never indiscriminate visual noise.

## Route And Structure

- Tech/digital: one device, UI, tool, comparison, or risk made physical; focused/shocked human reaction when useful.
- Interview/business/creator: recognizable guest or expert, dialogue/status tension, clean face separation.
- Knowledge/history: one consequence, conflict, before/after, or surprising object; avoid textbook flatness.
- Gaming: game identity plus one decisive character, item, loot, rank, or moment; preserve factual assets.
- Vlog/lifestyle: retain creator personality and event/story cue; use calmer taste only when the channel reference supports it.

Use a visual order of title/hook, face or hero object, then proof cue. Choose one structure: big face plus object pressure, face-to-face conflict, central hero with asymmetric text, or object-led comparison. Giant Chinese type is a visual object, but use few words and no tiny text. Give the hero the strongest scale, detail, contrast, and rim separation; backgrounds support it.

## Finish And Copy

Build from supplied assets whenever possible. If absent, use plausible photographed/composited production rather than an illustration-like AI poster. Use hard but clean cutouts, intentional shadows, one coherent light direction, limited accent colors, and only approved Chinese copy. Do not invent ranking, date, badge, UI, slogan, or metadata.

## Check

At small mobile size, the hook must be legible, the focal person/object unmistakable, and layers distinctly separated. Reject equal visual weight, over-detailed backgrounds, fake cinematic haze, unreadable small Chinese text, arbitrary neon, generic template arrows, or a YouTube-style treatment that ignores Bilibili's denser Chinese-feed grammar.
