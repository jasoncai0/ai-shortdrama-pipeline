# Shortdrama Cover Reference

Use for shortdrama/short drama/短剧/微短剧/竖屏短剧/ReelShort/DramaBox/GoodShort. Default 3:4; use 16:9 or 9:16 only when explicitly requested. “Vertical/portrait” alone remains 3:4. For overseas/non-Chinese distribution also load `shortdrama-overseas.md`.

## Locks Before Style

Lock market and visible-text language from exact title/copy first, then explicit platform/market, then user language. Exact title stays verbatim: do not shorten, translate, add brackets, slogans, genre tags, subtitles, or decorative text. If only a title is supplied, it is the only visible text.

Treat uploaded actor/role images as source-of-truth, map each to the correct role, and preserve face, wardrobe, age range, and role hierarchy. Obtain authorization before recognizable likeness use. Exact visual replication requires attached image references; text-only prompting cannot promise it.

Story genre does not select medium. If no reference or explicit medium settles it, ask once whether the production is live-action, comic/manju, anime, or 3D/CGI. Live-action stays here; intentional comic/anime/CGI execution may additionally use the manju reference.

## Mode And Visual Grammar

Reference mode follows the supplied layout/weight/type/light logic without copying IP. Discovery mode locks title, cast hierarchy, genre promise, aspect ratio, and one dominant cover grammar. Remix mode merges only reusable composition, type, lighting, or pose traits.

For domestic live-action, use one of: intimate two-lead close-up, single lead with a decisive prop/conflict, or family/power pyramid. Make relationship or reversal legible immediately. Use cinematic yet real camera framing, biological skin texture, imperfect light behavior, plausible hair/fabric, lens depth, and clean compositing; forbid beauty-filter plasticity, wax skin, CGI faces, and role swapping.

Match visual system to the story: warm polished romance/wealth, period family texture, court/power depth, high-contrast comeback/male fantasy, or quieter emotional distance. Title treatment may be dramatic but must remain exact and readable; use at most two type faces and three decoration families.

## Prompt And Check

Every generation prompt states: 3:4 unless overridden; locked language; exact allowed text; no subtitle/caption/genre/style label/repeated title/microcopy; role-to-image mapping; and, for humans, realistic skin, optics, lighting, and anti-CG constraints. Use search only when it materially improves an otherwise uncertain visual grammar and no stronger reference exists.

Before delivery verify ratio, title language and wording, title readability, role fidelity, relationship hierarchy, genre cue, realistic material/light, safe title space, no wrong-language UI, no invented labels, and no duplicate/title-only variants.
